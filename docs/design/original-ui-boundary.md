# Original UI/UX boundary

## Decision

GGEN's interface will be designed independently after task analysis and accessibility requirements. Reference apps inform only capability lists and failure lessons.

## Prohibited design inputs

- copying screenshots or screen hierarchy;
- deriving palette/typography/icons from BG or RGEN;
- matching navigation, inspector layout, toolbars, cards, dialogs, editor arrangement, or motion;
- using protected templates as the application chrome/brand.

## Required design process

1. Define user groups and top manual workflows.
2. Create information architecture from GGEN's UDM/workspace model.
3. Establish an original brand and design tokens in a separate approved decision.
4. Prototype phone/tablet/desktop adaptive layouts.
5. Validate touch, mouse, keyboard, and stylus flows.
6. Run accessibility and performance budgets before implementation.

No final logo, color, font, iconography, or navigation pattern is approved in Phase 0.
