# ADR-0003 — Desktop-class professional tool quality

**Status:** Accepted by owner, 2026-08-19

## Decision

Every GGEN creative tool targets professional computer-quality semantics. Mature software categories—3D DCC, font engineering, raster/photo editing, vector design, digital painting, document layout and PDF editing—are capability and quality benchmarks.

GGEN does not copy any reference product's UI, brand, icons, proprietary assets or implementation. Feature breadth is phased and claims remain evidence-based.

## Consequences

- Shared professional tool/session/command/preset contracts are built before many surface tools.
- Mobile UI adapts access, not underlying precision or file model.
- Every tool needs numeric precision, undo, cancellation, persistence, accessibility, interoperability, resource limits, tests and documentation.
- Early releases intentionally contain fewer complete tools rather than many demo-quality buttons.
- Full Blender/FontForge/Photoshop/Illustrator/Infinite Painter breadth is a multi-phase roadmap and must never be advertised as current parity without proof.
