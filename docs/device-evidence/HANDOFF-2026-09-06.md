## Artifact Download Diagnosis

### Problem
`gh run download <run-id>` times out (120s default) when downloading 71MB APK artifacts from GitHub Actions.

### Root Cause Analysis
```
Artifact size: ~71MB
Download duration: ~152 seconds (observed)
Hermes terminal timeout: 120 seconds (default)
Result: gh run download exits with code 124 (timeout)
```

### Working Solution
Use authenticated GitHub API + curl directly:
```bash
# Get artifact download URL
ARTIFACT_URL=$(gh api repos/soobujmiah/ggen/actions/artifacts/<id>/zip --jq '.download_url')

# Download with authentication (token injected by genv)
curl -L -H "Authorization: token $GH_TOKEN" -o app-debug.apk "$ARTIFACT_URL"
```

## Known Platform Limitations

### Android 16 Touch Input Restrictions
- **sendevent blocked:** `/system/bin/sendevent` writes to `/dev/input/event7` blocked by SELinux despite shell having group 1004 (input)
- **Three-finger limitation:** `monkey --pct-pinchzoom` only generates 2-finger simultaneous touch events
- **Volume key interception:** Android media session captures hardware volume keys before Flutter's `HardwareKeyboard.instance.addHandler()` receives them

### Workaround Required
Implement debug intent interface in MainActivity.kt to bypass ADB input limitations for testing.
