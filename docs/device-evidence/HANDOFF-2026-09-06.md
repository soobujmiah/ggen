## Known Issues

### 1. patch_debug_interface.py was broken
Previous version wrote Kotlin code into manifest.xml instead of creating proper Android activity class. Fixed in this commit — script now correctly:
- Creates `DebugActivity.kt` in kotlin source directory
- Patches `AndroidManifest.xml` with `<activity>` entry
- Idempotent (skips if already patched)

### 2. Volume key interception is Android platform limitation
Flutter's `HardwareKeyboard.instance.addHandler()` receives volume keys AFTER Android media session consumes them. Fix options:
- Implement custom MediaSession in MainActivity.kt
- Use debug intent interface instead (bypasses key event entirely)

### 3. Three-finger redo requires genuine 3+ pointer touch
Monkey's `--pct-pinchzoom` only generates 2-pointer gestures. Options:
- Debug intent interface (`redo` action)
- Physical keyboard simulation (requires rooted device or AOSP)
- Manual testing by owner
