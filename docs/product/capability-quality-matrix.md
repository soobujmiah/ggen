# Capability and Quality Matrix

This is a roadmap benchmark, not a statement that these features are currently implemented.

| Studio | Professional reference class | Required GGEN foundations | First useful milestone | Long-term depth |
|---|---|---|---|---|
| Vector | Illustrator / Infinite Design class | Bezier geometry, nodes, styles, transforms, snapping, artboards, SVG/PDF fidelity | select/draw/edit paths and shapes with exact inspector | booleans, appearance stack, symbols, patterns, advanced typography |
| Raster/photo | Photoshop / PicsArt class | tiled raster, layers, masks, blends, color, selections, filters, history | crop/transform/adjust/mask/layers/export | high-bit depth, retouch, smart/non-destructive filters, color management, AI tools |
| Painting | Infinite Painter class | low-latency stroke engine, stylus events, brush graph/presets, tiled canvas | pressure brush/eraser, layers, undo, canvas navigation | texture/scatter/wet media, symmetry, assistants, advanced blend dynamics |
| 3D DCC | Blender class | native scene/render engine, dependency graph, resource limits, glTF | PBR viewport, scene objects, picking/transforms, glTF | modeling/sculpt/UV/material/rig/animation/simulation/render/composite |
| Font | FontForge/pro type-editor class | shaping engine, font project schema, Bezier glyphs, OpenType validation | glyph browser, outline/metrics edit, shaping proof | kerning/classes/features, variable masters, validated multi-format export |
| Document | professional page-layout class | UDM, typography, pages/layers/styles, job/export | editable page with text/image/vector and PDF | masters/tables/data merge/preflight/print/color/accessibility |
| PDF | professional PDF editor class | bounded parser, object/fidelity model, signatures/security policy | inspect/annotate/reorder/merge/export safely | editable text/vector where representable, forms, redaction, preflight, tagged PDF |
| AI creative | provider-agnostic local/cloud class | AI router, evidence, secure keys, jobs/history | optional reviewed operation returning editable result | generation/edit/reconstruction across image/document/font/3D/workflow |

## Status at repository head

- Product/architecture documentation: implemented.
- Protected RGEN bytes/manifests: verified locally.
- Application/tool implementation: not yet present at the time this matrix was written.
- Phase 1 foundation begins only after the documentation commit containing this standard.
