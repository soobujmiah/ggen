# Reference lessons

## Preserve

- BG's credible segmentation/mask pipeline concepts.
- RGEN's exact layout and regression methodology.
- explicit CPU fallback and offline operation.
- real source/device evidence and failed-experiment history.

## Improve

- capability/evidence states rather than hardware-name guesses;
- monotonic real phase timers;
- explicit resource ownership and cancellation;
- bounded, streamed imports and batches;
- canonical storage and SAF;
- production signing/SBOM/provenance;
- complete license/asset register;
- implementation/build/emulator/device state separation.

## Never cross

No reference UI screenshot, layout, palette, typography system, icon set, component tree, route structure, animation, or brand element may be used as a GGEN design input. Functional tests may use abstract fixtures; protected production assets are available only inside document adapters/canvases after Phase 4.
